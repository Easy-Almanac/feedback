# Easy Almanac feedback

This is the public place to report bugs, ask questions and suggest features for [Easy Almanac](https://easyalmanac.com/?utm_source=github&utm_medium=feedback), the D&D campaign manager.

**This repository has no code.** Easy Almanac is not open source.

## How to help

- **Found a bug?** [Report it](../../issues/new/choose) and say what you did, what you expected, and what happened.
- **Have an idea?** [Suggest a feature](../../issues/new/choose). If someone already suggested it, add a 👍 to that issue instead, so we can see what people want most.
- **Want to talk it through?** Use [Discussions](../../discussions) or join our [Discord](https://discord.gg/YpJRYmTXuN).

## Links

- [Try the demo](https://easyalmanac.com/demo/?utm_source=github&utm_medium=feedback) (no sign-up)
